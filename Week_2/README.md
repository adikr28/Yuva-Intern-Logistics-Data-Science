# Week 2 – Data Collection, Cleaning, and Preprocessing

This week extends the Week 1 logistics strategy by building a reproducible data-preprocessing plan for the Olist Brazilian E-Commerce Public Dataset.

## Focus Areas
- Data collection simulation
- Data profiling and quality assessment
- Missing-value analysis and treatment
- Duplicate and key-integrity checks
- Timestamp parsing and chronology validation
- Outlier detection using the IQR method
- Categorical standardization
- Feature engineering for logistics KPIs
- Standardization and prevention of data leakage
- Final model-ready dataset validation

## Deliverable
The detailed Week 2 report documents the methodology, rationale, and Python examples used for each preprocessing stage.

## Dataset
Olist Brazilian E-Commerce Public Dataset:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The raw dataset is intentionally not stored in this repository. Download it from the public source and place the CSV files under `data/raw/` when running the pipeline locally.
